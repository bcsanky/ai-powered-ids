# Figures könyvtár

Ez a könyvtár a dolgozatba szánt ábrák futási kimeneteinek rendezett helye lehet. A `figures/final/` alatti PNG állományok automatikusan előállított eredményfájlok, ezért nem kerülnek Git verziókezelésbe.

Dolgozatba csak olyan ábra emelhető be real-lab bizonyítékként, amely verified real_lab provenance-hez kapcsolódó mérési csomagból származik. Demo vagy offline ábra legfeljebb demonstrációs illusztrációként használható, mérési benchmarkként nem.
